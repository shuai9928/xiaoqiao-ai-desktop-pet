## 当前完整接入（I-47，2026-10-09 CST）

在 I-45 双模式上继续实现 Claude 的 [CrossPet 移植规格](CROSSPET_PORT.md)。当前有 Claude、Codex、Gemini、DeepSeek、GLM 五主角色与五彩蛋包，共 232 张原图；角色配色覆盖左栏、工作台、聊天、菜单与互动卡片。素材仍是离散姿态与变体，不是连续骨骼动作。三个有效眨眼包只在对应 idle 底图上闭眼；Gemini 无眨眼，GLM 的重绘眨眼图保留但不播放。

`ai_pet` 负责有限视觉时间轴与角色台词，`ai_work` 只解释已有公开状态，`ai_fx` 负责小幅运动、淡入和左栏效果。阅读、编写、执行、委派、等待、出错、完成可驱动所选角色；临时摸头或打哈欠之后回到当前工作姿态。闲时十分钟休息，用户主动休息不会被工作事件唤醒；喂糖只给角色视觉反馈。分时段问候、节日姿态、额度高用量的疲倦与 Codex 周期恢复使用现有经过期判断的数据，没有新账户调用。

Windows 前台映射现包括 ZCode.exe→GLM、deepseek harness.exe→DeepSeek。仅 AI 模式跟随可靠原生前台，手动固定优先；Mac 和后台任务不抢外观。小乔的 nap、坐姿 Action、rig 与奖励仍归原引擎；AI 模式不调用她的语音，切模式会停止本实例拥有的在途朗读。已打开聊天的草稿、历史、焦点与等待状态保留。

本轮890隔离单元＋190/190兼容烟测通过，零失败/错误/跳过；263文件哈希守卫安装后，正常桌面实例逐个验证五主角色摸头、睡醒、戳一下及恢复工作，小乔模式保留。当前恢复 AI/auto、原隐藏 nap/缩放/视图/尺寸；验证期间位置发生改变，保留最新位置，验证指令不重定位桌宠。自定义角色包已有配置协议，导入/编辑界面、浏览器/终端产品识别、完整连续主动作与性能 p95 仍未验收。以下是 I-45 的历史记录；其中四角色、七姿态和未接入 ZCode 等限制已由 I-47 覆盖。

## I-45 历史记录（2026-10-08）

## 本轮目标与边界

用户主动选择“小乔桌宠”或“AI 桌宠”。缺省和旧设置保留小乔；只有 AI 模式跟随可靠识别的前台 AI。普通应用、未识别的网页、桌宠自己的窗口和后台任务保留当前可用外观，不以窗口标题中的普通词猜测产品。

外观是独立显示选择，不改变当前工作流任务、聊天模型、额度账户或会话采集。显示 Claude、Codex、Gemini 或 DeepSeek 的角色，不代表相应产品或 Claude 云端已接入；缺失的来源与额度仍如实显示未知。

本轮接入四套已有静态角色姿态和配套主题配置，不重写小乔接触网格、秋千物理或 Action 权限。自定义导入、任意包编辑 UI、浏览器网页自动识别和连续主动作 Sprite 不列为当前能力。

## 素材事实

CrossPet 四个正式角色包是透明静态 WebP：Claude 铜橙长发与书，GPT 白龙形象，Gemini 紫发猫耳，DeepSeek 深蓝女仆鲸鱼形象。GPT 的本地显示标识可对应 Codex，但图片来源与原署名保持 GPT。相同姿态下的变体可用于有限状态显示，它们不是可按时间连续播放的动画 clip，也没有小乔的 rig／接触锚点。

此前主题参考图是含模拟工作流与额度的设计图，不能作为可执行皮肤或真实账号证据。本轮实际覆盖范围以生产代码和预览为准，保留现有信息层级与状态颜色含义，不将参考图中的模拟数据带入运行。

### 模块

| 模块 | 负责 |
| --- | --- |
| `appearance.py` | 角色包注册与校验（清单、哈希、文件头、越界路径、预算），姿态首次绘制才解码并缩到 ≤400px 高；`AppearanceSelector` 两模式、固定形象、0.5 秒稳定跟随、拖动延后；运行中丢图整包退回 |
| `foreground_ai.py` | 前台 HWND → PID → exe 文件名，只读文件名，2 秒内同一窗口复用 |
| `ui_themes.py` | 五套主题（小乔沿用现有常量逐值一致；四套 AI 主题按参考图取底色／强调／边线派生），覆盖工作台、聊天、气泡、右键菜单与互动卡片；状态灯颜色不随主题变 |
| `apple_ui.Palette`、`ui3d.calm_panel/calm_button` 的可选配色参数 | 同一 API 换色；默认输出与改动前逐像素一致 |
| `appearance_ui.retheme_chat` | 已打开的聊天窗原地换色：草稿、记录、滚动位置、等待气泡保留，不重开窗口 |
| `flat_workspace.push` → `Pet._static_look` | AI 模式左栏画静态姿态（1.4u 呼吸起伏、单击一跳，减少动画时关闭），跳过小乔秋千层、帽上背层与头部标记；窗口留白按 `_hat_fx_layout_on` 计算，换外观不改窗口尺寸 |
| `assets/characters/` | CrossPet 四角色各 7 个姿态（idle／thinking／waiting=asking／happy／sleep／error=oops／listening）、`registry.json`、各包 `manifest.json`、原始许可 |

Windows 前台映射：`claude.exe`→Claude，`ChatGPT.exe`／`codex.exe`→Codex（Codex 桌面版在 Windows 的进程名是 ChatGPT.exe），`antigravity.exe`→Gemini，`deepseek.exe`→DeepSeek。ZCode、终端、浏览器、资源管理器与桌宠自身不映射，保持当前外观。

### 尚未实现

自定义角色包导入与编辑界面；浏览器网页／终端里 AI 的识别；AI 角色的连续动作（现为静态姿态＋轻微起伏）；参考图里的边饰与纹理（现只取配色与边线）；聊天窗标题、“正在想”提示和互动卡片的星光／好感仍是小乔口吻与数据。

审核重点（本轮已对照）：

- 模式和外观有独立身份，默认值与设置保存不被任务筛选或模型选择覆盖。
- 角色和主题作为一个可用组合切换；包缺失、坏图、未知配置、越界路径或预算超限可靠回退，不空白、不残留上一角色部件。
- 加载／解码不进入每帧热路径，缓存有限且带角色、资源版本与尺寸身份；切换不累积无界缓存。
- 场景拖动期间保留当前外观，松开后只应用最新请求；打盹保留，睡眠不被换外观唤醒。已排队的单击在换外观时作废，长按害羞只属于小乔。
- 静态 AI 姿态与小乔程序动作分别处理，缺姿态使用该包 idle，运行中丢图整包退回小乔与魔女紫。
